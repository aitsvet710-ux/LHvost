# Ласточкин хвост

Дайджест столярного ремесла: инструменты, чертежи, техника и приёмы, безопасность, события и
вдохновение для тех, кто работает с деревом.

Статический сайт на Astro + Tailwind CSS v4. Материалы собираются из Telegram, RSS и YouTube,
нормализуются, фильтруются, раскладываются по рубрикам, переводятся на русский и складываются в
`data/materials.json`.

## Быстрый старт

```bash
npm install
cp .env.example .env      # ключи не обязательны: без них работает fallback
npm run collect           # собрать материалы в data/materials.json
npm run dev               # локальный сервер на http://localhost:4321
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер разработки с горячей перезагрузкой |
| `npm run build` | Сборка статического сайта в `dist/` |
| `npm run preview` | Локальный просмотр собранного сайта |
| `npm run collect` | Сбор материалов из источников в `data/materials.json` |
| `npm run backfill:translations` | Перевод уже собранных иноязычных материалов на русский |

## Рубрики

`Инструмент` · `Проект/чертёж` · `Техника и приёмы` · `Безопасность` · `События/выставки` ·
`Вдохновение`

Новые рубрики добавляются в три места: union `Category` в `src/lib/types.ts`, ключевые слова в
`scripts/categorize.ts`, метка в `src/components/Tag.astro`. Существующие рубрики не переименовываются.

## Источники

Источники описаны в `src/config/sources.json`: Telegram, RSS и YouTube. Смена источника — правка
`scripts/collect.ts` и/или добавление адаптера; интерфейс о внешних источниках ничего не знает.

Чтобы включить источник, поставьте ему `"enabled": true`. Адаптеры изолируют сбои: если один
источник недоступен, остальные продолжают работают, а `npm run collect` не падает.

## Конвейер сбора

`npm run collect` выполняет шаги строго по порядку:

1. **Адаптеры** — `telegram.ts` (публичная лента `t.me/s/<канал>`), `rss.ts` (`rss-parser`),
   `youtube.ts` (RSS-мост канала по `channel_id`). Каждый адаптер возвращает пустой массив при
   сбое и печатает предупреждение — сбор не прерывается.
2. **normalize** — `scripts/normalize.ts`: чистка HTML, обрезка служебных хвостов, приведение
   даты к ISO, определение типа контента.
3. **filter** — `scripts/filter.ts`: отсев рекламы, вакансий и материалов без практической
   ценности.
4. **categorize** — `scripts/categorize.ts`: рубрика по ключевым словам и до 4 тегов.
5. **summarize** — `scripts/ai/summarize.ts`: краткое описание через OpenRouter. Без ключа
   используется fallback — первые 200 символов описания.
6. **Запись** — `data/materials.json`. Материалы дедуплицируются по адресу, история сохраняется,
   повторный запуск не добавляет одни и те же записи.

Если ни один источник не ответил, конвейер подставляет демонстрационные материалы, чтобы сайт
оставался рабочим. Как только появляются настоящие данные, демо-записи удаляются.

Каждый материал в `data/materials.json` содержит обязательные поля: `id`, `slug`, `title`,
`summary`, `url`, `source`, `sourceType`, `contentType`, `category`, `publishedAt`, `tags`.

## Доступ к данным на сайте

`src/lib/data.ts` — единственная точка чтения материалов:

| Функция | Что возвращает |
| --- | --- |
| `getAllMaterials()` | Все материалы, свежие сверху |
| `getFreshIssue(days, limit)` | Свежий выпуск за N дней |
| `getMaterialBySlug(slug)` | Материал по адресу страницы `/<slug>/` |
| `getCategories()` | Рубрики, в которых есть материалы |
| `getSources()` | Названия источников |
| `getContentTypes()` | Типы контента |

## Страницы и фильтры

| Адрес | Что показывает |
| --- | --- |
| `/` | Hero и свежий выпуск — до 7 последних материалов |
| `/archive/` | Все материалы по месяцам, фильтры и поиск |
| `/<slug>/` | Страница материала: рубрика, теги, первоисточник, похожие |

Фильтры архива живут в query-параметрах, поэтому ссылку на отфильтрованную подборку можно
сохранить или отправить: `?category=<слаг>&source=<название>&type=<тип>`. Например,
`/archive/?category=technique` показывает только рубрику «Техника и приёмы».

Поиск по заголовку, краткому содержанию и тегам работает на клиенте, без внешних библиотек.

## Ключи и переменные окружения

Ключи хранятся только в `.env` (файл в `.gitignore`). Шаблон с именами переменных без значений —
`.env.example`:

| Переменная | Назначение |
| --- | --- |
| `OPENROUTER_API_KEY` | Суммаризация и перевод материалов через OpenRouter |
| `LLM_API_KEY` | Запасной ключ OpenAI-совместимого API |
| `IMAGE_GEN_API_KEY` | Генерация обложек по рубрикам (необязательно) |
| `TELEGRAM_SESSION` | Прямой сбор из Telegram (необязательно) |

Без ключей конвейер не падает: суммаризация берёт первые 200 символов описания, перевод
пропускается, материал помечается как оригинал.

## Как отключить перевод

В `src/config/ai.json` в блоке `translation` поставьте `"enabled": false`. Модель перевода задаётся
только там — в коде она не зашита. Кэш переводов лежит в `scripts/cache/translations.json` и
коммитится: повторный запуск сбора не делает новых запросов к API.

## Визуальный слой

- Главная: hero, полоса метрик (`StatsBand` — материалы, рубрики, источники, дата обновления) и
  сетка рубрик (`CategoryGrid` — клик открывает архив с фильтром).
- Карточка материала показывает обложку рубрики 16:9, бейдж рубрики, заголовок, краткое содержание,
  источник, дату и время чтения.
- Страница материала: обложка во всю ширину с градиентом, полоса прогресса чтения, блоки
  «Коротко» и «Подробнее», теги, ссылка на первоисточник и похожие материалы.
- Состояния: подъём карточек, фокус-кольца у кнопок и чипов, затухание края ленты чипов на
  мобильном.
- Обложки — собственная векторная графика проекта в WebP 1600×900 (`public/images/categories/`),
  лицензия на изображения не требуется. Выбор обложки — в `src/lib/covers.ts`.

## Инварианты

Коротко — подробно в [AGENTS.md](AGENTS.md):

1. Все внутренние ссылки — через `withBase()` из `src/lib/utils.ts`.
2. Tailwind v4: тема только в `@theme`, повторяемые стили — через `@utility`. Файла
   `tailwind.config.mjs` нет.
3. Ключи — только в `.env`, никогда не коммитить.
4. `npm run collect` не падает на пустых ответах, отсутствии ключа и таймаутах.
5. Весь текст интерфейса — на русском.
6. `main` защищена: feature-ветка, PR, squash-merge, Conventional Commits.
